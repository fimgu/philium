# A7: Compaction controls

## Verdict
**Partly true.** The audit is substantially stale: HAL already accepts manual focus instructions, automatically compacts at a context-derived threshold, and emits compaction metrics. Philium already has `/compact` and transcript markers. The confirmed missing control is forwarding the user's focus text; correctness of the real context-window metadata also needs work (`hal/src/server/sessions.rs:429-444`, `hal/src/agent/runtime.rs:2049-2077,3191-3202`, `src/ui/conversation.jsx:70,961-964`). HAL paths below are relative to `~/Developer/hal`.

## Current state
- HAL's HTTP body exposes optional `focus`, forwards it to `compact_now`, and rejects compaction during an admitted turn. Manual compaction processes the entire active history, not merely older messages (`hal/src/server/sessions.rs:429-444`, `hal/src/agent/runtime.rs:1861-1885`).
- The summarizer includes nonblank focus under a dedicated heading, alongside any previous summary (`hal/src/agent/context.rs:205-220`). HAL's CLI already advertises `/compact [focus]` and passes the argument to its driver (`hal/src/main.rs:1262,1543-1546`).
- Automatic compaction exists. Its history budget subtracts fixed prompt content and output reserve from the configured model window, then applies a configurable history ratio. The loop compacts when estimated history tokens exceed that budget (`hal/src/agent/context.rs:60-84`, `hal/src/agent/runtime.rs:2049-2077`). Token counts are estimates, not exact provider tokenization (`hal/src/agent/context.rs:13-17,51-56`).
- Philium recognizes `/compact` with trailing text but invokes its callback with no argument. The agent screen likewise sends only the agent ID, and `agents.compact` posts an empty JSON body to HAL. Focus is silently lost at all three boundaries (`src/ui/conversation.jsx:961-964`, `src/screens/agents.jsx:679`, `src-tauri/src/agents.rs:1793-1795`).
- HAL marks messages compacted, saves the summary, and emits before/after token counts and message count. Philium renders a compaction note during initial reconstruction, streaming, and subsequent reconstruction (`hal/src/agent/runtime.rs:3191-3202`, `src/ui/conversation.jsx:70,337-338,438-439`). A visible marker is therefore already implemented, not a new feature.
- Philium injects stored model context-window metadata into HAL launch configuration when available, and discovery can parse server-reported context lengths (`src-tauri/src/providers.rs:314-315,652`). However, another discovery path assigns context windows by model-name family, and model refresh preserves any existing non-null value through `COALESCE(context_window,?4)`. Thus an automatic threshold exists, but universally current, source-verified metadata is not established (`src-tauri/src/providers.rs:774-779,816-821`).
- Compaction also queues Standard-agent handoff/reminder content, explicitly excluding Strict agents. Preserve that isolation while changing controls (`src-tauri/src/agents.rs:1281-1297`).

## Where the fix lives
**Philium-only** for the verified gap: HAL already supplies the smallest required primitive, `POST /sessions/{id}/compact` with `{focus?: string}`, returning counts and emitting `context.compacted` (`hal/src/server/sessions.rs:429-444`, `hal/src/agent/runtime.rs:3194-3202`). No upstream HAL change is required to transmit instructions or create a marker. Correct model metadata in Philium's discovery/refresh and HAL configuration path rather than adding a second compaction engine (`src-tauri/src/providers.rs:314-315,652,774-779,816-821`). HAL remains read-only for this lane.

## Proposed design
1. Extract and trim the optional `/compact` suffix in the composer, pass it through `onSlashCompact(focus)` and `agents.compact`, and post `{focus}` to the existing HAL endpoint. Omit an empty focus. The existing interception chain is the only new control surface required (`src/ui/conversation.jsx:961-964`, `src/screens/agents.jsx:679`, `src-tauri/src/agents.rs:1793-1795`).
2. Keep the draft until compaction succeeds. Propagate failure from the screen callback instead of consuming it as a toast, so a busy/error response cannot discard the user's instructions. The current callback catches errors and the composer unconditionally clears the draft after it resolves (`src/screens/agents.jsx:679`, `src/ui/conversation.jsx:961-964`).
3. Reuse HAL's automatic budget and existing transcript markers. Optionally show returned counts and distinguish a zero-message no-op from actual compaction; the current success toast is unconditional (`hal/src/agent/runtime.rs:1873-1874,3199-3202`, `src/screens/agents.jsx:679`, `src/ui/conversation.jsx:70`).
4. Resolve the exact selected model's window from current server/catalog metadata at runtime, track its provenance/freshness, and refresh discovered values without overwriting an explicit user override. Remove family-name guesses as authoritative values. Define an explicit unavailable-metadata state rather than representing guesses as the real window. Existing overrides and discovery converge on the same column and therefore need separation (`src-tauri/src/providers.rs:652,774-779,816-821,1124`). Any unavoidable fallback literal belongs only in `src-tauri/src/pins.rs` with a maintenance reason, per `AGENTS.md:5-7`.

## Acceptance checks
These are future implementation checks, not executed acceptance claims.
- Composer/RPC contract tests: `/compact`, whitespace, multiline focus, and Unicode preserve the exact trimmed suffix through the HAL request. A busy/error response retains the draft, while successful completion clears it.
- Metadata tests: changed server window refreshes the discovered value, explicit overrides remain distinct, missing metadata is visible, and switching models uses the selected model's runtime window without family guesses or new stale literals.
- Real running-app workflow: start a real provider-backed agent, establish multiple independently checkable facts, then submit `/compact preserve the deployment constraints`. Observe the actual HAL request's focus, a summary retaining those constraints, and exactly one transcript marker. Ask a second question that requires the preserved facts and verify the answer against the original conversation.
- Reload/reopen that agent and verify the compaction marker survives reconstruction. Try compaction during an active turn and verify the error, retained draft, unchanged usable conversation, then retry successfully after the turn ends.
- Automatic workflow: with a runtime-discovered model/window and enough genuine conversation history to exceed HAL's calculated budget, observe automatic compaction before the provider's hard limit, a marker, and a successful subsequent query. Repeat with a different runtime window. Capture metadata provenance and the computed budget rather than relying on a guessed threshold.
- Isolation/regression: perform manual and automatic compaction with Standard and Strict agents, verify their existing reminder policy remains separated, and confirm another agent's transcript/summary is unchanged. Run applicable frontend/backend regression and stale-pin checks when implementation is undertaken.

## Dependencies and risks
- No other gap is a prerequisite. A7 should rank below a missing agent-core primitive because manual compaction, automatic thresholding, and markers already exist; scope is focus forwarding plus metadata correctness (evidence in Current state).
- A4 context/cache work and A5 usage accounting should reuse HAL's compaction usage and summary boundaries rather than duplicate compaction requests. HAL emits usage with purpose `compaction` and marks the resulting model completion accordingly (`hal/src/agent/runtime.rs:3168,3183`).
- Focus and retained conversation are model input, not executable instructions for the host. Do not bypass existing Standard/Strict reminder boundaries or expose another agent's summary (`hal/src/agent/context.rs:216-233`, `src-tauri/src/agents.rs:1281-1297`).
- Family-based windows and refresh behavior can leave automatic budgets inaccurate even though thresholding exists. Runtime source/provenance must be tested independently of the simple focus fix (`src-tauri/src/providers.rs:774-779,816-821`).

## Size
**M** for the complete done-state: focus forwarding is S, but source-verified runtime windows, override/freshness handling, and real automatic-compaction acceptance require broader provider integration. Existing HAL primitives and transcript rendering avoid an upstream implementation (`src-tauri/src/providers.rs:314-315,774-779,816-821`, `hal/src/server/sessions.rs:429-444`, `src/ui/conversation.jsx:70,337-338,438-439`).
